
# Dart Programming Exercises

## Introduction
This project is a Flutter application developed to demonstrate five fundamental Dart programming concepts through interactive exercises.

## Exercises

### Exercise 1: Product Information
- Stores product information using variables.
- Displays product details.
- Demonstrates the difference between `final` and `const`.

### Exercise 2: Discount Calculator
- Receives product price and discount percentage.
- Converts string inputs into numeric values.
- Calculates the discount amount and final price.
- Validates user inputs.

### Exercise 3: Shopping List
- Creates an initial shopping list.
- Allows users to add new items.
- Allows users to remove existing items.
- Displays the updated list and item count.

### Exercise 4: Counter Using Closure
- Implements a counter using a Dart closure.
- Preserves the counter value between function calls.
- Increases the value through an interactive button.

### Exercise 5: Price Filter
- Stores a list of prices.
- Filters prices above a user-defined limit.
- Calculates and displays the sum of filtered prices.

## Technologies Used

## Project Features
- Five interactive exercises in one application.
- User input and real-time result display.
- Input validation.

## How to Run
1. Open the project in FlutLab.
2. Select the Web platform.
3. Click Build.
4. Run the application using Web Emulator.

## Conclusion
This project demonstrates fundamental Dart concepts, including variables, data types, type conversion, collections, functions, closures, and list operations through a practical Flutter application.
